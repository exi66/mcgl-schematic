# Схематики MCGL

Схематики [Minecraft Galaxy](https://minecraft-galaxy.ru/) прямо в браузере: 3D-просмотр, срезы, линейка и список
материалов.

**Открыть:** https://exi66.github.io/mcgl-schematic/

## Как открыть схематику

- Кнопка **«Открыть»** вверху: вставьте ссылку на файл или выберите файл с диска.
- Или просто **перетащите файл** `.schematic` в окно.
- Или передайте ссылку в адресе страницы:
  `https://exi66.github.io/mcgl-schematic/?url=<ссылка на .schematic>`

Поддерживается формат MCEdit `.schematic`. Файл по ссылке скачивается вашим
браузером, поэтому сайт с файлом должен разрешать это (CORS): подходят raw.githubusercontent.com, gist,
Discord CDN. Если файл не открывается по ссылке — скачайте его и откройте с диска.

Чтобы просто посмотреть, как всё работает, на стартовом экране есть **пример со всеми блоками**:
https://exi66.github.io/mcgl-schematic/?url=./examples/all-blocks.schematic

Файл с диска выбирается через окно браузера. Chrome, Edge и Opera в следующий раз откроют его в той же папке
(Firefox и Safari запоминают папку сами).

## Ссылка на вид

Адрес страницы меняется вместе с видом: скопируйте его, и по ссылке откроется та же схематика с того же места
(для файлов по ссылке; у файла с диска адреса нет). Параметры можно дописать и вручную:

| Параметр                     | Что задаёт                                                                    |
| ---------------------------- | ----------------------------------------------------------------------------- |
| `url=<ссылка>`               | Схематика по ссылке                                                           |
| `view=orbit\|plan\|explore`  | Режим: вращение, план, обзор                                                  |
| `slice=y:5`, `iso=1`         | Срез по оси до 5-го слоя (слои с 1); `iso=1` — только этот слой               |
| `cam=x,y,z`, `at=x,y,z`      | Положение камеры и точка, куда она смотрит; `rot=1..3` — поворот плана на 90° |
| `embed=1`                    | Только 3D-вид, без верхней панели (для встраивания)                           |
| `list=0` / `list=1`          | Список блоков свёрнут / показан                                               |
| `theme=dark` / `theme=light` | Тема                                                                          |

`list` и `theme` из ссылки действуют только на этой странице и не меняют ваших настроек. Остальные настройки
(тема, список блоков, «Отображение») браузер запоминает сам.

## Управление

Панель внизу:

| Кнопка          | Клавиша              | Что делает                                                                    |
| --------------- | -------------------- | ----------------------------------------------------------------------------- |
| Вращение        | `1`                  | Обычный 3D-вид. Левая кнопка — вращать, правая — двигать, колесо — приблизить |
| План            | `2`                  | Вид сверху, как на игровой карте: вверху −X, слева +Z                         |
| Обзор           | `3`                  | Прогулка по постройке от первого лица (см. ниже)                              |
| Срез            | `L`                  | Показать постройку до выбранного слоя по X, Y или Z                           |
| Линейка         | `Shift` + перетащить | Измерить область: размеры и число блоков внутри                               |
| Отображение     |                      | Сетка, подписи сторон, камера, анимация текстур, подсказки, фон               |
| Горячие клавиши | `?`                  | Все клавиши                                                                   |
| Полный экран    | `F`                  |                                                                               |

Ещё клавиши: `R` — вернуть вид, `Q` / `E` — повернуть на 90°, `O` — ортографическая камера, `G` — сетка на
полу, `M` — список блоков, `Esc` — снять выделение и измерение.

**Обзор.** Кликните по постройке, чтобы управлять мышью. `W A S D` — идти, мышь — смотреть, пробел — прыжок,
`Shift` — присесть (не упадёте с края). Двойной пробел — полёт сквозь блоки и обратно, в полёте пробел и `Shift` —
вверх и вниз, колесо — скорость. Двойное `W` — бег. `Esc` — отпустить мышь.

**Срез.** Ползунок справа выбирает слой (`[` и `]` — на слой, с `Shift` — на 10). Кнопка с глазом (`I`) —
показать только этот слой, а слой под ним — полупрозрачной подложкой.

**Блоки.** Клик по блоку — карточка с названием, ID, положением и описанием из игры. Подсказку при наведении
можно включить в «Отображении».

## Список блоков

Слева — все блоки схематики с количеством. Клик по строке скрывает этот блок, кнопка-прицел подсвечивает его.

**Экспорт** над списком — список материалов для форума (BBCode, с иконками предметов) или в Markdown:
скопировать или скачать файлом.

## Какие блоки поддерживаются

Блоки многоблочных структур и всё, что с ними связано: БАК, синтезатор урана и его структуры (барьер, энергомост, энергополе, телепорт, межсерверный портал, терраформер, дробилка), электросеть и водопровод, завод, печи, транспортные трубы, жидкости. Модели (насос, распределитель жидкости, контейнер плутония, компоненты завода, бетономешалка) и анимированные текстуры — как в игре. Сундуков, шкафов и цветных блоков пока нет.

## Для разработчиков

```
pnpm install
pnpm dev        # локальный сервер
pnpm test       # тесты
pnpm build      # сборка в dist/
```

Сайт публикуется на GitHub Pages при пуше тега `v*` (например, `v0.1.0`).
